# Causal Analysis in Medical Domain leveraging LLMs

This repository contains an adaptation of the [PyWhy-LLM](https://github.com/py-why/pywhyllm) library, customized for causal analysis in the medical domain as part of a Master's thesis project.


PyWhy-LLM is a library that integrates Large Language Models (LLMs) into the causal analysis process. It augments human expertise by providing LLM-assisted tools for:

- **Causal modeling**: Suggesting domain expertises, confounders, and causal relationships between variables
- **Identification**: Recommending backdoor sets, mediators, and instrumental variables
- **Validation**: Critiquing causal graphs, suggesting latent confounders, and identifying negative controls
- **RAG-based modeling**: Utilizing Retrieval-Augmented Generation for enhanced causal discovery

This project adapts PyWhy-LLM specifically for medical causal inference tasks and causal flow models.
